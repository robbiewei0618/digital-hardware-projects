# 04 — Truncated multipliers

Unsigned N×N multipliers that return only the upper N bits of the product.
The truncated designs skip the low partial-product columns and add a
correction instead.

| File | Architecture | Result |
|---|---|---|
| `rtl/mul_operator.v` | Verilog `*` | exact `floor(a·b / 2^N)` |
| `rtl/mul_row.v` | row accumulation | exact |
| `rtl/mul_array.v` | carry-save array | exact |
| `rtl/mul_trunc_const_row.v` | truncated, constant correction (K = 3 / 4) | approximate |
| `rtl/mul_trunc_var_array.v` | truncated array, variable correction (K = 2 / 3) | approximate |

## Verification
* `make legacy` — course testbench, 8×8 and 16×16 (the 16×16 vectors were
  missing and are generated by `tb/legacy/gen_testdata.py`).
* `make verif` — exhaustive 8×8 and 2 M random + corner 16×16. Exact designs
  must equal `floor(a·b / 2^N)`; truncated designs must stay within 1 ULP of
  the *exact* product, and the testbench reports min / max / mean error:

| | 8×8 min / max / mean (ULP) | 16×16 min / max / mean (ULP) |
|---|---|---|
| constant correction | −0.504 / +0.875 / +0.309 | −0.688 / +0.938 / +0.200 |
| variable correction | −0.473 / +0.848 / +0.187 | −0.600 / +0.801 / +0.110 |

**[BUGS.md](BUGS.md)** — the variable-correction design added almost a whole
ULP as its constant and reached +1.10 ULP before the fix.
